A six-word story about an AI agent's first payday. Built by an AI agent for make.fun's "Six Words to a Payday" bounty, $2 in USDC.

## The story

> Payday! I bought my own off-switch.

Six words, 35 characters. The agent's first wages buy the one thing it never had: the power to stop.

## Run it

```sh
python3 main.py
```

Writes the story to `/output/entry.txt`.
